# Security policy

This repository is a packaging proof of concept and does not publish supported
binary releases. Security support and vulnerability handling for Electron,
FreeLens, Kubernetes, Helm, and other upstream components remain with their
respective projects.

For a vulnerability in this repository's packaging scripts, patches, or build
process, use the hosting service's private security-advisory mechanism. Do not
open a public issue containing an unpatched vulnerability, credential, private
artifact URL, or other sensitive information.

Reports should include the affected commit and package, reproduction steps,
impact, and any proposed mitigation. Never attach private keys, access tokens,
or proprietary source artifacts.
